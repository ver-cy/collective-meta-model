# Contributing

Contributions are welcome through GitHub pull requests.

- Read `BOOTSTRAP.md` and follow the canonical walk.
- Use English for canonical normative names and text.
- Keep public `collective.*` CSNs immutable.
- Do not collapse independent matrix graphs or copy sovereign external master data.
- Add provenance, compatibility, migration, and changelog information for semantic changes.
- Run `node tools/validate.mjs` and validate both JSON documents against their schemas.
- Sign commits using the Developer Certificate of Origin (`git commit -s`).

Substantive changes should explain the problem, proposed semantics, alternatives, compatibility impact, and affected invariants.
